# Game Tracker

Одностраничная лента новых страниц Steam для поиска идей для двухдневных прототипов в Roblox. Карточки открывают страницы игр в Steam. Логотип и шапка основаны на Duck Places.

## Как обновляется лента

GitHub Actions каждые 15 минут по расписанию просматривает список Coming Soon по тегам инкрементальных игр, физики, пати, кооператива и простых симуляторов. Первый полный проход создаёт исходный список. Следующие проходы находят новые App ID в этих выборках и проверяют, что в Steam это публичная страница ещё не вышедшей игры. Автоматическая оценка учитывает теги и краткое описание. Сложность прототипа зависит от того, какую механику перенести в Roblox.

Карточки живут в ленте до 14 дней с первого обнаружения или до выхода игры. Дата на карточке показывает, когда страницу заметил трекер. Это важно, например, когда существующая страница позже получает подходящий тег. Стартовые карточки отобраны вручную из [недавних событий SteamDB](https://steamdb.info/history/events/) и сверены в Steam. Дальнейшие проверки используют только Steam.

Ветка `feed` хранит состояние сканера и публичный `feed.json`. Vercel читает ленту через `/api/games`, поэтому новые карточки появляются без пересборки сайта. Открытая страница проверяет ленту каждую минуту. GitHub может задержать запуск по расписанию.

## Локальный запуск

Нужны Node.js 24 и доступ к Steam. Установка зависимостей не требуется.

```sh
npm run update
npm run dev
```

Сайт откроется на [localhost:4173](http://127.0.0.1:4173). Локальное состояние записывается в `.feed/`.
